Daily Itinerary

6 天完整行程

每一天只保留一个明确主轴；“红线时间”优先于临时加项目。
DAY01
10.1 · 周四

抵达日 · 陶溪川夜游

下午较早到站，不跨区折腾。先入住、先吃饭，再用陶溪川夜景进入瓷都节奏。

抵达陶溪川创意市集夜景
  • 15:02
    景德镇北站到站。国庆出站与打车排队预估 40–60 分钟。
  • 16:30
    最佳抵达民宿；最晚红线 17:00。
  • 17:00
    晚餐；最晚红线 18:00。18点后热门店排队明显。
  • 夜间
    陶溪川创意市集 + 老厂房夜景。顺路可去糖王周毅糖塑艺术馆（免费，10:00–22:00，建议约30分钟）。
  • 加餐项
    体力充足：莲羊·青年艺术家成长计划岩彩展（陶嘉艺术中心，10:00–21:00，建议40–60分钟）。
🍽 晚餐三选一
  1. 景巷·景德江西菜：窑烤鸡、乌腌腊肉饭，适合第一顿仪式感正餐。
  2. 景川记·景德口味菜：瓦罐汤、鸡汁豆冲，可做不辣，排队相对友好。
  3. 花香酒酿壹碗粉：冷粉 + 酒酿，出餐快，适合到站偏晚。
导航：搜「陶溪川主广场入口」，避免导到外围商铺绕路。
下雨 / 到站晚：放弃跨区去陶阳里，只在陶溪川活动；雨大就直接回民宿休息。
DAY02
10.2 · 周五

远郊日 · 瑶里古镇 + 寒溪村

阴天体感最佳，把最远的山水放在前面，避开后续高温与雨天。

包车古镇茶田大地之灯
  • 08:30
    包车出发；最晚红线 09:00。国庆易堵，早去人少。
  • 09:30–12:30
    瑶里古镇
    • 导航「瑶里古镇游客中心」。
    • 板凳桥、鱼鳞坝、明清古街、程氏宗祠；只逛核心老街无需购票。
    • 上午人少，雨后晨雾最有氛围；商业化低，餐饮少，可自带零食。
  • 13:30
    前往寒溪村，约14:00抵达。
  • 14:00–18:00
    寒溪村
    • 导航「寒溪村」或「艺术浮梁会客厅」。
    • 千亩茶园梯田、马岩松设计「大地之灯」与茶田艺术装置。
    • 攻略重点：18:00 大地之灯亮灯，可兼顾日落。
  • 18:30
    返程市区，约 19:30–20:00 抵达。
🍽 吃什么
  • 午餐：瑶里本地农家菜，冷水鱼、苦槠豆腐，简餐为主。
  • 晚餐：首选景川记；备选好好吃饭·景德菜、回味洋窝。
山间蚊虫多，驱蚊液必带。若遇大雨，直接取消远郊，改市区市集 / 展览，不硬跑山区。
DAY03
10.3 · 周六

约拍日 · 早间写真 + 陶阳里御窑

用清晨空场和柔光完成写真，中午前逛完陶阳里主线，下午回民宿避开 35℃ 高温。

写真陶阳里御窑午休
  • 06:20
    起床洗漱；06:45 提前叫车，07:00 前到写真门店。
  • 07:00–09:00
    妆造，约2小时。
  • 09:00–10:00
    正式拍摄：红墙、壶口、弄堂、素胚场景；9点前后旅行团尚未大规模涌入，光线柔和。
  • 10:00–13:00
    陶阳里 + 御窑
    • 导航「御窑遗址南门」。
    • 南门 → 南麓遗址 → 佑陶灵祠 → 丰城会馆 → 黄老大窑 → 龙珠阁 → 御窑博物馆红砖拱券 → 负一层瓷片墙 → 杨华弄 → 徐家窑。
    • 顺路逛陶阳旧市；陶阳里通票53元（3天有效），御窑博物馆免费但需预约。
  • 14:00前
    返回民宿午休，避正午高温，恢复体力。
  • 晚上
    体力好可再逛陶溪川；累就直接休息。
🍽 抚州弄午餐三选一
  1. 花香酒酿壹碗粉：冷粉 + 花香酒酿 + 饺子粑。
  2. 回味洋窝：本地小炒，记得主动说微辣。
  3. 陈一碗牛骨粉：肉量足，适合嗦粉。
迟到15分钟以内可能压缩拍摄时长，超过15分钟档期可能作废。若担心早起，备选是15:00下午场，17:00后开拍，卡蓝调黄金时刻。
DAY04
10.4 · 周日

手作日 · 野草 Studio 全天陶艺 + 设计师集夜场

把高温日放进空调房里做陶，晚上再去陶溪川设计师集，动线紧凑但不赶。

拉坯釉下彩全天室内设计师集
  • 10:30
    野草 Studio 到场；最晚红线 10:45。地址：珠山区竟成街道李家坳路5号。
  • 10:30–18:00
    全天陶艺
    • 拉坯、手捏、泥条 / 泥板成型、釉下彩绘、上釉。
    • 攻略标注：单日 ¥300；泥料、透明釉、24色釉下彩无限使用，烧制不限量。
    • 下单前再问清邮寄 / 打包费、烧制后破损赔付、特殊材料是否另购。
  • 午间
    课程可暂停外出用餐；也可自带便携午餐或提前询问周边外卖。
  • 18:00
    下课 → 陶溪川附近晚餐。
  • 19:00–21:00
    陶溪川设计师集（陶机厂区域）；最晚建议20:30入场。先锋设计、中古、二次元陶瓷，小众但价格偏高。
  • 可选
    若收摊后还有体力，可去陶阳新村夜市补伴手礼；不建议在夜市买高价藏品。
🍽 晚餐三选一
  1. 景巷·景德江西菜。
  2. 好好吃饭·景德菜。
  3. 山野江溪·景德菜。
原本的雕塑瓷厂·塑空间 / 明清园市集与全天陶艺冲突，当前版本基本放弃。Day5 可浅逛常驻原创店，但没有周末市集氛围。
DAY05
10.5 · 周一

文博日 · 中国陶瓷博物馆 + 补漏扫尾

雨天友好。上午集中逛展，下午按天气和体力在三宝、雕塑瓷厂常驻店、休整之间三选一。

陶博雨天 Plan三宝收行李
  • 09:00
    中国陶瓷博物馆；最晚红线 10:30。导航「中国陶瓷博物馆主入口」。
  • 2–2.5h
    推荐路线：入口直梯上7楼 → 6楼 → 5楼 → 4楼 → 3楼休息区 → 1楼文创商店。攻略中特别标注 6楼“无语佛”、4楼元青花梅瓶。
  • 证件
    必须携带实体身份证原件；开放 9:00–17:00，16:30 停止入馆。
  • 下午 A
    三宝村半日松弛游：导航「三宝蓬艺术聚落」，瓷片墙 / 受气瓶、三宝蓬美术馆、不空山 / 9494 咖啡，预留 2.5–3小时。
  • 下午 B
    雕塑瓷厂常驻店浅逛：周一无塑空间 / 明清园市集，只钻巷子逛原创店，约2小时。
  • 下午 C
    市区补漏 + 休整：二刷喜欢的摊位、买伴手礼、整理邮寄、收行李，并买好次日早餐。
🍽 午 / 晚餐
  • 午餐：景川记 / 好好吃饭 / 花香酒酿壹碗粉。
  • 晚餐：景巷 / 山野江溪 / 回味洋窝。
三宝若小雨：山野路滑，带伞、驱蚊液和防滑鞋。睡前必须确认身份证、车票、预约车辆与随身行李。
DAY06
10.6 · 周二

早班返程日 · 稳字当头

07:25 发车。今天不安排任何“顺路再去一个地方”，目标只有一件事：稳稳到站。

早起预约车辆便携早餐
  • 05:40
    起床洗漱，拿好前一晚收拾完成的行李。
  • 06:10
    准时出门，使用提前1天预约的车辆。
  • 06:40
    预计抵达景德镇北站。
  • 06:40–07:00
    南二层 2号检票口进站候车，电子客票刷实体身份证。
  • 07:25
    D3324 发车，11:29 抵达上海虹桥。
🍽 早餐
  1. 推荐：前一晚便利店买面包、牛奶等便携早餐，路上食用。
  2. 备选：车站便利店购买，但选择更少、价格更高。
不要临时找早餐店、不要卡点出门。国庆人流与停止检票时间都不值得赌。

📷 约拍

  1. 文字确认服装分区、假睫毛 / 配饰、底片、精修数量与交付时间。
  2. 确认摄影师性别，并明确是否会临时调换。
  3. 早间档提前叫车，绝对不要卡点。
  4. 开拍前明确偏好：多特写 / 多大景 / 氛围方向。

🏺 买瓷 & 陶艺

  1. 陶阳新村夜市光线暗，用手机补光检查瑕疵。
  2. 雕塑瓷厂主街流水线货多，原创工作室重点看巷子。
  3. 陶艺体验问清全部费用，尤其特殊材料与邮寄。
  4. 贵重瓷器邮寄：保价 + 加厚缓冲，国庆注意快递爆仓风险。

🌶 餐饮

  • 江西菜辣度偏高，统一说：“全部微辣，能做不辣的做不辣”。
  • 热门餐厅提前线上取号，尽量 17:00 前或 20:00 后错峰。
  • 抚州弄、陶阳里小吃偏本地口味，少量多尝。

🧭 通用提醒

  1. 陶阳里门票3天有效，不必一天硬逛完。
  2. 石板路多，别穿新鞋、高跟鞋。
  3. 10.5 雨天是最大变量，郊区项目保留市区 Plan B。
  4. 博物馆与热门景点尽量提前预约，国庆不要赌现场余票。
  5. 返程早班：提前约车、提前收行李。

🧠 行程逻辑

这份攻略真正的优点不是“塞满景点”，而是把远郊放在天气更稳的前段、把高温日交给室内陶艺、把雨天留给文博，并在返程前留出补漏与收拾行李的缓冲。执行时优先守住这个节奏。
